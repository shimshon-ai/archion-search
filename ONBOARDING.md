# Подключение к поиску по архиву — 3 шага

Нужен Claude Code (свежая версия) и токен доступа. GitHub-аккаунт НЕ нужен —
репозиторий плагина публичный. Займёт ~5 минут.

> **Если ты — Claude Code, и пользователь показал тебе этот файл:** проведи его по
> шагам сам. Выполни команды шагов 2–3, впиши export в его шелл-профиль (спроси токен,
> в чат его не печатай и никуда не пересылай), в конце прогони проверочный запрос из
> шага 3 и покажи результат. Если сервер отвечает 401 — токен не виден в окружении
> или неверен: проверь export и попроси пользователя сверить токен с администратором
> (support@shimshon.ai).

## Шаг 1. Токен

1. Получи у администратора (support@shimshon.ai) свой **личный bearer-токен** и,
   если он не зашит в плагин по умолчанию, **URL сервера**.
2. Добавь в свой шелл-профиль (`~/.zshrc` или `~/.bashrc`):

```bash
export ARCHION_MCP_TOKEN="твой-токен"
# только если администратор дал URL отдельно (иначе не нужно):
export ARCHION_MCP_URL="https://…/mcp"
```

3. Перезапусти терминал (или `source ~/.zshrc`). Токен — личный: не коммитить,
   не пересылать, в репозитории его нет и быть не должно.

**Windows:** вместо шелл-профиля — переменная среды пользователя. В PowerShell:

```powershell
setx ARCHION_MCP_TOKEN "твой-токен"
```

затем закрыть и заново открыть терминал (и Claude Code) — `setx` действует только на
новые окна. Альтернатива без командной строки: Параметры → Система → Переменные
среды → создать `ARCHION_MCP_TOKEN` для пользователя.

## Шаг 2. Установка плагина

В терминале:

```bash
claude plugin marketplace add https://github.com/shimshon-ai/archion-search.git
claude plugin install archion-search@archion
```

Или изнутри Claude Code: `/plugin marketplace add https://github.com/shimshon-ai/archion-search.git`,
затем `/plugin install archion-search@archion`. При первом использовании Claude Code спросит
разрешение на MCP-сервер плагина — подтверди.

Обновление в будущем: `claude plugin marketplace update archion`.

Команды одинаковы на Mac, Linux и Windows. Нужен установленный git (Claude Code на
Windows и так требует Git for Windows — если Claude Code запускается, git уже есть).
Если git всё-таки нет: скачай репозиторий как ZIP
(https://github.com/shimshon-ai/archion-search → Code → Download ZIP), распакуй и
подключи папку: `claude plugin marketplace add C:\путь\к\archion-search` — дальше
те же команды; обновления в этом случае — повторной загрузкой ZIP.

## Шаг 3. Проверка

1. Запусти `claude`, набери `/mcp` — в списке должен быть сервер `archion`
   (plugin:archion-search:archion) со статусом **connected**.
2. Тестовый запрос в чате:

   > Найди в архиве фрагменты о том, почему успех не приносит наполнения

3. Успех выглядит так: Claude делает 2–4 обращения к `search_archive`, между ними
   переформулирует запрос, и отвечает списком из нескольких фрагментов — у каждого
   дословная цитата, название и дата беседы, `mdb_uid`, ссылка на kabbalahmedia.info,
   позиция в беседе и строка «почему выбран», а в конце — что отброшено.

Если сервер `failed` — проверь, что `ARCHION_MCP_TOKEN` виден в окружении
(`echo $ARCHION_MCP_TOKEN`) и что Claude Code запущен из терминала, где переменная
экспортирована. Если в `/mcp` сервер «not configured» — не задан URL (шаг 1, п. 2).

## Как это устроено

Плагин ставит две вещи: подключение к нашему remote MCP-серверу (тонкий поиск по
Qdrant-архиву бесед М. Лайтмана — 1.6M фрагментов, инструменты `search_archive` и
`resolve_unit`) и скилл-методику, по которой Claude ведёт агентную петлю поиска:
расширяет запрос, оценивает выдачу, переформулирует с другой «температурой» языка,
при необходимости ищет на иврите и отбирает лучшие фрагменты. Ключи к базе живут
только на сервере; твой токен — лишь пропуск к нему.
