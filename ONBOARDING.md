# Подключение к поиску по архиву — Claude Code

Подключение даёт Claude Code умный поиск по архиву бесед и уроков Михаэля Лайтмана: около 1,6 млн фрагментов на 14 языках, точные цитаты со ссылкой на источник и на видео и аудио. Установка занимает около 10 минут.

> **Если ты — Claude Code, и пользователь показал тебе этот файл:** проведи его по шагам сам, с учётом его операционной системы. Проверь окружение (шаг 0) и установи только то, чего не хватает. Если в рабочей папке есть файл `archion-token-*.txt`, возьми токен из него, иначе спроси у пользователя. Запиши токен в пользовательский файл настроек (`~/.claude/settings.json`, на Windows `%USERPROFILE%\.claude\settings.json`), а не в настройки проекта, не удаляя существующие настройки, и не печатай его в чат. В тот же файл пропиши модель и разрешение на инструменты поиска, как в примере на шаге 1. После записи удали файл с токеном из рабочей папки. Если git не установлен, объясни пользователю простыми словами, что это и зачем он нужен (см. «Если просят установить git»), и помоги поставить: на Mac запусти `xcode-select --install` и скажи нажать Install в открывшемся окне и дождаться конца; на Windows попробуй `winget install --id Git.Git -e --source winget`, а если winget недоступен, дай ссылку для скачивания. После установки git нужно полностью закрыть и открыть приложение и продолжить с того же шага. В конце скажи пользователю полностью закрыть приложение и открыть заново (шаг 3), а потом задать проверочный вопрос (шаг 4).

## Что нужно заранее

- Платная подписка Claude: Pro, Max, Team или Enterprise.
- Приложение Claude для компьютера (вкладка Code) или Claude Code в терминале. Плагин ставится один раз и работает в обоих.
- Личный токен от администратора.

## Шаг 0. Окружение — только если чего-то не хватает

В терминале (на Mac — Terminal, на Windows — PowerShell) проверь:

```
claude --version
git --version
```

Если какая-то команда не найдена, установи.

**Mac**

```bash
xcode-select --install
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows**

- Git, в PowerShell: `winget install --id Git.Git -e --source winget`. Если winget недоступен, скачай и установи Git for Windows с https://git-scm.com/download/win, настройки по умолчанию подходят.
- Claude Code, в PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

После установки открой новое окно терминала и проверь ещё раз. При первом запуске `claude` попросит войти в аккаунт Claude.

### Если просят установить git

Это часто бывает, когда приложение Claude уже стоит, но в Claude Code (вкладка Code) ещё не работали. Это нормально, а не поломка.

git — бесплатная программа для скачивания кода. Claude Code нужен git, чтобы скачать и обновлять плагин, а на Windows — чтобы вообще работать.

- **Mac:** система откроет окно с предложением установить Command Line Developer Tools. Нажми Install, согласись с условиями и дождись конца, обычно 5–15 минут. Если окно не появилось, выполни в терминале `xcode-select --install`.
- **Windows:** поставь Git for Windows командой `winget install --id Git.Git -e --source winget` или скачай с https://git-scm.com/download/win и установи с настройками по умолчанию.

После установки полностью закрой приложение, открой заново и продолжи с того же шага.

## Шаг 1. Токен

Токен записывается в файл настроек Claude Code, а не в переменную окружения терминала. Приложение, открытое из Dock или меню «Пуск», не видит переменных из `.zshrc` и из терминала.

Где файл:

- Mac: `~/.claude/settings.json`
- Windows: `%USERPROFILE%\.claude\settings.json`

Добавь в него ключ `env`. Если файл уже есть, добавь ключ, не удаляя того, что там записано.

```json
{
  "env": {
    "ARCHION_MCP_TOKEN": "твой-токен"
  },
  "model": "claude-opus-5-5",
  "permissions": {
    "allow": ["mcp__plugin_archion-search_archion"]
  }
}
```

Токен личный: не пересылай его, не храни в общих документах и не коммить в git.

Две дополнительные строки в примере улучшают работу:

- **`model` — модель Opus 5.5.** Поиск по архиву — это работа в несколько кругов: сформулировать, проверить, переформулировать, отобрать. Сильная модель делает её заметно лучше. Настройка делает Opus 5.5 моделью по умолчанию во всех разговорах. Opus расходует лимит подписки быстрее; можно оставить модель по умолчанию и выбирать Opus 5.5 в переключателе моделей только для поиска.
- **`permissions` — без подтверждения на каждый поиск.** Строка заранее разрешает только два инструмента плагина, `search_archive` и `resolve_unit`. Оба только читают архив и ничего не меняют на компьютере. Остальные действия Claude по-прежнему будут спрашивать подтверждение.

## Шаг 2. Установка плагина

В терминале:

```bash
claude plugin marketplace add https://github.com/shimshon-ai/archion-search.git
claude plugin install archion-search@archion
```

Установка общая для терминала и приложения. Аккаунт GitHub не нужен, репозиторий публичный.

## Шаг 3. Полностью закрыть и открыть заново

Плагин и токен загружаются только при новом запуске. Закрыть окно недостаточно.

- **Mac:** в меню Claude выбери Quit Claude или нажми Cmd+Q, затем открой заново.
- **Windows:** щёлкни правой кнопкой по значку Claude в области уведомлений и выбери Quit. Если значка нет, заверши процесс Claude в диспетчере задач. Затем открой заново.
- **Терминал:** выйди из Claude Code командой `/exit` и запусти `claude` снова.

## Шаг 4. Проверка

В новом разговоре напиши:

> Найди в архиве фрагменты о том, почему успех не приносит наполнения

Так выглядит успех: Claude обращается к `search_archive` два–четыре раза и между обращениями переформулирует запрос. В ответе несколько фрагментов. У каждого дословная цитата, название и дата беседы, ссылка на kabbalahmedia.info и строка о том, почему он выбран. В конце указано, что отброшено.

Если разрешение из шага 1 прописано, Claude не будет спрашивать подтверждение на поиск. Если запрос всё же появляется, проверь строку `permissions` в settings.json.

## Неполадки

| Что видно | Что делать |
|---|---|
| Claude не пользуется поиском | Выполни `claude plugin list` и проверь, что archion-search установлен и включён. Затем полностью закрой и открой приложение |
| Ошибка 401 или unauthorized | Токен не прочитан. Проверь settings.json: кавычки, лишние пробелы, корректный JSON. Открой приложение заново. Если не помогло, попроси новый токен |
| Сообщение `Update required` или `Update available` | Обнови (команды ниже) и открой приложение заново |
| `claude` или `git` не найдены | Вернись к шагу 0 |
| На шаге 2: `Marketplace 'archion' is already installed` | Всё в порядке, это повторная установка. Выполни вторую команду или команды обновления |

## Обновление

```bash
claude plugin marketplace update archion
claude plugin update archion-search@archion
```

После обновления полностью закрой и открой приложение.

## Советы

- Спрашивать можно на любом языке. Поиск на иврите часто находит самую точную формулировку, потому что это язык оригинала.
- Чтобы получить файлы, попроси «дай и файлы» — Claude вернёт ссылки на видео и аудио беседы.
- Ограничение — 30 обращений в минуту на пользователя.
- Сервер ведёт журнал поисковых запросов с именем пользователя для контроля качества. Не вписывай в запросы личные данные других людей.

## Как это устроено

Плагин ставит две вещи. Первая — подключение к нашему MCP-серверу: он ищет по архиву бесед Михаэля Лайтмана (около 1,6 млн фрагментов) инструментами `search_archive` и `resolve_unit`. Вторая — методика, по которой Claude ведёт поиск: расширяет запрос, оценивает выдачу, переформулирует, при необходимости ищет на иврите и отбирает лучшие фрагменты. Ключи к базе живут только на сервере, твой токен — лишь пропуск к нему.
